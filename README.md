# 💫 About Me

I'm an SDET at **PharmEasy**, one of India's largest digital healthcare platforms. I test the APIs and
microservices behind pharmacy, diagnostics and Plus/Pro membership flows before they reach millions of users.

- 60+ REST APIs and microservice integrations validated with **Rest Assured (Java), Postman and Playwright**
- 45+ defects found in a single major feature, 15+ of them backend issues, before production
- 17 automated scenarios in Rest Assured and Playwright for coupon validation and UI flows
- A Jenkins-triggered utility that cut order status changes from half a day to 5 minutes
- Started as a backend intern at LG Electronics (Java, Spring Boot, MySQL), so I read code and logs while testing

## 🔭 Featured project

**[Api-Test-Automation](https://github.com/Btwitsdksh13/Api-Test-Automation)**: a Java + Rest Assured + TestNG framework
